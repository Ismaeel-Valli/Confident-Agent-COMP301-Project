# Statistical Analysis

| Path | Content |
|---|---|
| `Unprocessed Data/evaluation/` | the evaluator's output: `report.md` (primary result, McNemar, bootstrap intervals, per-API figures), `self_check.json`, and per run `evaluation.json`, `per_task.jsonl`, `review_queue.csv`, `audit_sample.csv` |
| `Unprocessed Data/stats/` | the stats compiler's CSV tables, per quantization and combined; columns in `STATS_README.md` |
| `analyse_results.py` | Wilcoxon tests on time, energy and tokens per run, and the charts |
| `figures/` | charts written by `analyse_results.py` |

`Unprocessed Data` is regenerated by `Findings/EvaluateBenchmark` (`python
evaluate_benchmark.py`, then `python compile_stats.py`). Do not edit it by hand: put
processed data, notebooks and charts beside it.

The rules behind every figure (classes, primary outcome, statistics) are in
`Findings/Benchmark/EVALUATION_PLAN.md`. Undetermined candidates stay out of the rates
until the manual review (plan §4) is entered in `Findings/EvaluateBenchmark/reviews/reviews.csv`
and both scripts are rerun.
